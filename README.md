# Sunny Bee Portfolio

Personal portfolio of Phạm Anh Tuấn, a web developer based in Da Nang, Viet Nam. Built with React, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm start
```

The site opens at http://localhost:3000.

## Scripts

- `npm test`: run the tests
- `npm run build`: create the production build in `build/`

## Updating content

- Projects: the `projects` array in `src/pages/Projects.jsx`. Add demo or source links to `links`.
- Skills: the `skills` array in `src/pages/Skills.jsx`.
- Experience and certificates: the arrays at the top of `src/pages/Resume.jsx`.
- CV file: replace `public/pdf/CV.pdf`.
